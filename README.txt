日本地震速報監控中心 - 使用說明

檔案：index.html

一、執行方式
1. 將 JapanEarthquakeMonitor 資料夾解壓縮。
2. 使用 VS Code 開啟資料夾。
3. 安裝並啟用 Live Server 擴充功能（或使用其他本機 HTTP 靜態伺服器）。
4. 右鍵 index.html，選擇 Open with Live Server。
5. 網頁需連接網際網路，才能載入 Leaflet 地圖、OpenStreetMap 圖磚及 P2Pquake API。

二、目前已整合功能
- P2Pquake WebSocket API v2 即時接收 551、552、554、555、556。
- 依 P2Pquake message id 去重，支援斷線後漸進式重連。
- 551 一般地震資訊與各觀測點震度列表／分布統計。
- 556 EEW 報文、取消、事件編號與報數追蹤。
- 顯示 556 areas 預估震度及來源提供的 arrivalTime 倒數；未提供則不推算。
- 依使用者輸入的預報區域關鍵字比對關注區域，設定儲存在瀏覽器 localStorage。
- 552 海嘯警報／注意報、預報區域、第一波到達時間及高度欄位。
- 554 EEW 發表檢知、555 P2P 連線節點數統計。
- 近期 551／552／556 歷史資訊及事件時間軸。
- 音效啟用、瀏覽器桌面通知、模擬警報。
- 震央 Leaflet 地圖、P/S 波概念動畫（僅教學示意）。
- JMA 官方地震、推計震度、海嘯及長周期地震動資訊連結。

三、重要限制
- 本頁的即時資料只有 P2Pquake WebSocket 一個即時轉發來源；歷史資料使用 P2Pquake History API。JMA 網站目前以官方資訊連結方式提供，尚未直接整合 JMA XML 或授權即時 EEW 予報服務。
- P2Pquake 官方規格說明其 EEW 轉發資料內容及配信品質無保證，不建議作為正式緊急地震速報唯一來源。
- P2Pquake 556 提供的區域名稱與預測欄位，不等於一般向け官方 EEW 警報的所有公開資訊。到達時間僅在資料欄位實際提供時顯示。
- 552 海嘯資料由 P2Pquake WebSocket 推送；歷史查詢不是即時備援來源。
- 本版沒有假裝直接產生「日本全國官方震度著色面圖」或 250m 推計震度網格。當前資料中的 551 points 是測站／區域文字及震度，沒有每個點的地理座標；需要額外取得並整合官方測站座標或 JMA 推計震度網格資料才能正確繪製。
- 長周期地震動資料沒有從目前 P2Pquake 551／552／554／556 欄位自動取得，故提供 JMA 官方最新觀測結果連結。
- P/S 波動畫採用假設速度，只用來說明波傳播概念，不是當次地震的實際波前、預測或警報。
- 瀏覽器音效需先由使用者點擊啟用；桌面通知需授權，且通常只在分頁未顯示時通知。
- 請避免同時開啟多個本頁分頁，P2Pquake WebSocket 有每個 IP 的連線數限制。

四、建議下一階段
若要將 JMA XML、長周期地震動觀測資料、250m 推計震度網格及授權 EEW 預報資料納入，建議增加 ASP.NET Core 後端服務作為資料整合層，再使用 SignalR 推送至前端。不要在瀏覽器端硬編造倒數或震度分布。
